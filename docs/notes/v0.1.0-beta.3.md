# Release Notes (Draft): v0.1.0-beta.3

Release date: TBD  
Base comparison: `v0.1.0-beta.2` -> `origin/dev`  
PR target: `dev` -> `main`

## Summary

This release candidate introduces major Beta improvements to schema rendering and navigation, especially for nested object usability and local `$ref` support, plus demo tooling upgrades and broader test coverage.

## Highlights

- Added local same-document `$defs`/`$ref` support in rendering and validation, including bounded recursive reference scenarios.
- Added collapsible nested object surfaces with persisted UI-only expand/collapse state.
- Added collapsed object summary chips with overflow handling (`...`) and invalid-field visibility cues.
- Added summary-chip navigation that expands ancestors and focuses target fields without mutating values.
- Added branch selection inference from populated initial/default/controlled values.
- Added `Clean` form action; `Reset` now appears only when `defaultValue` is explicitly provided.
- Improved enum-array behavior: unique enum arrays use checkbox/multiselect controls, non-unique enum arrays use repeatable select rows.
- Added demo-side schema builder/editor and proto-schema conversion workflow.

## API And Behavior Notes

- `JsonSchema` typing now includes `$ref` and `$defs`.
- `onSubmit` now accepts async handlers (`Promise` return support).
- Local `$ref` node siblings such as `title`, `description`, and `default` are preserved in resolved rendering context.
- Validation sanitization now recursively sanitizes `$defs` while leaving local `$ref` resolution to Ajv.

## Documentation And Config Review

- `README.md` and `docs/ARCHITECTURE.md` were expanded for local refs, collapsible summaries, and Storybook usage.
- Added `src/css.d.ts` to support CSS side-effect imports in TypeScript builds.
- Set `vitest` timeout to `10000` in `vite.config.ts` for test stability.
- Updated `docs/ARCHITECTURE.md` non-goals wording to match current publish workflow reality.
- Publish workflow still enforces strict version/tag parity: GitHub Release tag must equal `v${package.json version}`.
- Prerelease versions publish with npm tag `beta`.
